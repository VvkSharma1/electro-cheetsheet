# Electromagnetics Midsem Cheat Sheet

A two-page, printable HTML study sheet covering selected electromagnetics, transmission-line, and plane-wave topics.

## Contents

The sheet includes:

- Wave fundamentals, phasors, guided and unguided waves
- Electric and magnetic field quantities, material parameters, and Maxwell's equations
- Vector operators and electromagnetic boundary conditions
- Power and energy relationships
- Transmission-line models, reflection coefficient, standing waves, SWR, and input impedance
- Conceptual spectrum scanning notes

The HTML uses MathJax to render equations and includes print-oriented A4 landscape styling.

## View

Open the [published cheat sheet](https://vvksharma1.github.io/electro-cheetsheet/).

## Source

The source is [index.html](index.html). It identifies *Electromagnetics, Volume 1* by Steven W. Ellingson as a reference for some course modules. The sheet is a study aid; consult the source text and course materials for full explanations and verification.
